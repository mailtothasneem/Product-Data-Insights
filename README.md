# Product-Data-Insights

  Excel-based product dataset project focusing on data cleaning, category validation, typo correction, and handling missing values. 

Description

   Product‑Data‑Insights is an Excel‑based project designed to showcase practical data cleaning, validation, and analysis techniques on a structured product dataset. The worksheet includes attributes such as Product ID, Manufacturing Date, Country Code, Product Name, Brand Name, Price, Quantity, Category, and Total Price.

Executing Program

To run and explore the **Product‑Data‑Insights** project:

1. Open the file `Excel-Raw Data.xlsx` in **Microsoft Excel** (2021 or later recommended).
2. Review the dataset columns:
   - Product ID  
   - Manufacturing Date  
   - Country Code  
   - Product Name  
   - Brand Name  
   - Price  
   - Quantity  
   - Category  
   - Total Price  
3. Apply Excel formulas and functions to:
   - Clean inconsistent text formats  
   - Handle missing values  
   - Validate categories and brands  
   - Calculate total prices (`Price × Quantity`)  
4. Save your analysis results in the same workbook or export them as needed.
